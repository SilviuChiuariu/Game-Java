# 🎮 Java Game

A 2D game developed in **Java**, featuring a custom game engine, player movement, enemies, objects, maps, AI and a database system.

## 🚀 Features

* 🎮 Player movement and interaction
* 🗺️ Tile-based game world
* 👾 Multiple enemies and monsters
* 🤖 Enemy AI and pathfinding
* ⚔️ Combat and player health system
* 🎒 Objects and items
* 💰 In-game objects and interactions
* 🧩 Collision detection
* 🎥 Camera movement
* ⌨️ Keyboard and mouse input
* 🗄️ Database integration
* 💾 Game data management
* 🧱 Custom game map and environment
* 🔄 Game loop and event handling

## 🧠 Game Systems

The project contains several systems that work together to create the game:

* **Player system** – handles movement, interaction and player state.
* **Enemy system** – manages different types of monsters and their behaviour.
* **AI system** – provides enemy movement and pathfinding.
* **Object system** – manages interactive objects and items.
* **Tile system** – builds and manages the game world.
* **Collision system** – detects interactions between entities and the environment.
* **Event system** – handles keyboard and mouse input.
* **Database system** – stores and manages game-related data.

## 🛠️ Technologies

* Java
* Java 2D
* SQLite
* Object-Oriented Programming
* Pathfinding / AI

## ▶️ Running the project

### 1. Clone the repository

```bash
git clone https://github.com/SilviuChiuariu/Game-Java.git
cd Game-Java
```

### 2. Open the project

Open the project in an IDE such as **IntelliJ IDEA** or **Eclipse**.

Make sure a compatible **Java JDK** is installed.

### 3. Run the game

Locate the main class inside:

```text
src/main/
```

Run the project's main class from the IDE.

The game window should start automatically.
